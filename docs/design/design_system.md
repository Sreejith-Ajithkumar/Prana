# Design System — Initial Direction

## Brand

Prana should feel calm, premium, natural, intelligent, and trustworthy.

## Initial palette

- Deep green background: `#061A10`
- Primary green: `#5DBB63`
- Light green: `#9FE870`
- Soft accent: `#E7F6B5`
- Light background: `#F7FAF2`
- Main text: near black or white depending on theme

## UI principles

- Material 3
- Rounded cards
- Clear hierarchy
- Large readable headings
- Consistent spacing
- One primary action per screen
- Minimal typing during onboarding
- Strong accessibility contrast
