# Prana v0.6.0 — Weight & Progress

**Release type:** Internal development release  
**Sprint:** Sprint 6 — Weight, Goal Pace & Progress  
**Development branch:** `feature/weight-progress`

## Highlights

v0.6.0 introduces Prana's first complete long-term progress experience.

### New

- historical weight logging
- persistent weight history
- weight source model for future health integrations
- latest-weight handling
- multi-day trend weight
- weight-loss, weight-gain, and maintenance goal directions
- progress percentage toward goal
- goal-reached handling
- weight history/trend chart
- persistent weekly goal pace
- estimated target date
- DST-safe target-date calculation
- recent actual pace analysis
- planned-vs-recent pace comparison
- minimum-history guardrails for pace reporting
- swipeable Today ↔ Progress dashboard
- independent tab scroll-position retention
- embedded Progress experience with Log Weight
- cleaner Profile without redundant Progress navigation

## User experience

The dashboard now exposes:

```text
Today | Progress
```

Users can tap or swipe between them. Today remains focused on daily nutrition and meals; Progress focuses on long-term weight and goal movement.

## Weight trend rules

- latest measurement per calendar day
- minimum 3 distinct measurement days
- up to 7 recent daily measurements averaged
- latest weight used before trend becomes reliable

## Recent pace rules

- latest measurement per calendar day
- minimum 3 measurement days
- minimum 14-day span
- maximum 28-day lookback
- linear regression
- ±20% initial tolerance for “close to plan”

## Planning rules

Goal pace is user controlled. Target date is an estimate, uses calendar-day-safe arithmetic, and does not automatically alter nutrition targets.

## Data and privacy

v0.6.0 remains offline-first. Weight history and goal pace are stored locally. No cloud sync is introduced in this release.

## Known limitations

- kilograms only
- local storage only
- no Apple Health integration yet
- no Health Connect integration yet
- no wearable synchronization yet
- no smart-scale ingestion yet
- no automatic nutrition reference-weight adaptation
- target-date estimates assume a selected average weekly pace
- recent pace requires at least 14 days of history
