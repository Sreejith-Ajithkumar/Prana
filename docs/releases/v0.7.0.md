## User experience

### Today

The Today dashboard can now show health activity separately from nutrition:

```text
Steps
Active energy
Workouts
Workout time
```

Activity energy does not change the nutrition target.

### Health & Wearables

Profile now links to a platform-aware Health & Wearables experience.

On Android, Prana uses Health Connect.

On iOS, Prana uses Apple Health.

The screen explains what Prana reads and keeps the integration read-only and user controlled.

## Weight synchronization

Prana imports approved/available body-weight measurements into the existing weight history.

Health Connect:

```text
health-connect:<externalId>
WeightSource.healthConnect
```

Apple Health:

```text
apple-health:<externalId>
WeightSource.appleHealth
```

Re-syncing updates an existing imported record when its source identity matches instead of creating duplicate entries.

Manual weights remain untouched.

## Permission behavior

### Health Connect

Android can expose per-category access. Prana supports partial activity access and shows which metrics are connected.

### Apple Health

Apple keeps individual read-permission decisions private.

Prana therefore uses:

```text
Access not requested
Access reviewed
```

rather than claiming that each Apple Health read category is connected or denied.

After authorization has been reviewed, Prana attempts reads and displays only data Apple Health makes available.

## Data and privacy

Sprint 7 remains offline-first for Prana-owned data.

Health integration is read-only.

Prana currently reads only the health categories required for implemented features:

- body weight
- steps
- active energy
- workouts

Prana does not write health changes back to Health Connect or Apple Health.

Activity calories are not automatically added back to the food budget.

## Known build warning

The `health` Flutter plugin still applies the legacy Kotlin Gradle Plugin.

Current builds succeed due to Flutter compatibility support.

Recheck plugin migration to Flutter Built-in Kotlin before a future Flutter/AGP upgrade.
